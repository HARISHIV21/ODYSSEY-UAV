# ODYSSEY UAV

### Software-Defined Autonomous UAV Navigation & Mission Computer

ODYSSEY UAV is a modular autonomous flight software platform implementing mission management, waypoint navigation, offboard control, telemetry acquisition, health monitoring, failsafe handling, flight-data recording, and post-flight analysis.

The system is developed and validated entirely in **Software-in-the-Loop (SITL)** using **PX4 Autopilot, Gazebo, MAVSDK-Python, and Python**, enabling autonomous UAV software development without physical flight hardware.

---

## Navigation Engine

Waypoint navigation is handled independently from the high-level mission state machine.

For each target, the navigation engine evaluates the UAV position relative to the commanded waypoint using the local NED coordinate frame.

The three-dimensional position error is evaluated as:

```text
distance = sqrt(
    north_error² +
    east_error² +
    down_error²
)
```

The waypoint is considered reached when the vehicle enters the configured arrival tolerance.

![ODYSSEY waypoint navigation](Images/03_waypoint_navigation.png)

This provides closed-loop mission progression based on measured PX4 telemetry rather than fixed timing assumptions.

## Failsafe Architecture

The mission computer includes a dedicated failsafe manager.

Monitored conditions include:

- vehicle-health status
- battery condition
- mission execution exceptions

When a critical mission exception occurs, ODYSSEY attempts to transition the vehicle to a safe condition by:

```text
Mission Failure
      |
      v
FAILSAFE
      |
      v
Stop Offboard Control
      |
      v
Command Landing
      |
      v
Disarm when appropriate
```

The architecture keeps failsafe handling separate from normal mission execution.

## Engineering Design Principles

ODYSSEY was structured around several software-engineering principles relevant to autonomous and embedded systems:

**Modularity** — mission execution, navigation, telemetry, safety monitoring, and analysis are separated into dedicated modules.

**State-based execution** — mission progression is represented explicitly through mission states rather than a single procedural flight script.

**Telemetry-driven navigation** — waypoint completion depends on measured vehicle position.

**Safety separation** — failsafe handling is isolated from nominal mission execution.

**Configuration-driven missions** — waypoint definitions are stored separately from navigation logic.

**Post-flight verification** — recorded telemetry is used to quantitatively evaluate mission execution.

import asyncio
import time

from MissionComputer.state_machine import StateMachine
from MissionComputer.mission_manager import MissionManager
from MissionComputer.mission_executor import MissionExecutor
from MissionComputer.battery_monitor import BatteryMonitor
from MissionComputer.health_monitor import HealthMonitor
from MissionComputer.failsafe_manager import FailsafeManager
from MissionComputer.logger import MissionLogger
from MissionComputer.flight_recorder import FlightRecorder


class MissionComputer:

    def __init__(self, flight_manager, mission):

        self.flight_manager = flight_manager
        self.mission = mission

        # Logging
        self.logger = MissionLogger()
        self.recorder = FlightRecorder()

        # State machine
        self.state_machine = StateMachine()

        # Vehicle monitoring
        self.battery = BatteryMonitor(
            flight_manager.drone
        )

        self.health = HealthMonitor(
            flight_manager.drone
        )

        # Mission manager
        self.mission_manager = MissionManager(
            flight_manager,
            mission
        )

        self.mission_manager.attach_state_machine(
            self.state_machine
        )

        # Mission executor
        self.executor = MissionExecutor(
            flight_manager,
            self.mission_manager
        )

        # Failsafe
        self.failsafe = FailsafeManager(
            flight_manager,
            self.battery,
            self.health,
            self.logger
        )

        # Flight recorder control
        self.recording = False
        self.recording_task = None

    async def flight_recording_loop(self):

        start_time = time.monotonic()

        print("[RECORDER] Waiting for telemetry...")

        # -------------------------------------------------
        # WAIT FOR MAVSDK TELEMETRY
        # -------------------------------------------------

        while self.recording:

            try:

                await self.flight_manager.telemetry.update()

                if self.flight_manager.telemetry.ready():
                    break

            except asyncio.CancelledError:

                return

            except Exception:

                # PX4 may still be completing connection
                await asyncio.sleep(0.5)

        if not self.recording:
            return

        print("[RECORDER] Live recording started")

        # -------------------------------------------------
        # RECORD FLIGHT DATA
        # -------------------------------------------------

        while self.recording:

            try:

                await self.flight_manager.telemetry.update()

                snapshot = (
                    self.flight_manager.telemetry.get_snapshot()
                )

                elapsed_time = (
                    time.monotonic() - start_time
                )

                try:

                    state = self.state_machine.get_state()

                    state_name = str(state)

                except Exception:

                    state_name = snapshot["flight_mode"]

                self.recorder.record(
                    elapsed_time,
                    snapshot["north"],
                    snapshot["east"],
                    snapshot["down"],
                    snapshot["battery"],
                    state_name
                )

            except asyncio.CancelledError:

                break

            except Exception as e:

                print(
                    f"[RECORDER] Telemetry warning: {e}"
                )

            await asyncio.sleep(1)

        print("[RECORDER] Live recording stopped")

    async def start(self):

        self.logger.mission_started()

        # Start recorder background task
        self.recording = True

        self.recording_task = asyncio.create_task(
            self.flight_recording_loop()
        )

        try:

            await self.executor.execute()

            self.logger.mission_completed()

        except Exception as e:

            self.logger.log_error(str(e))

            await self.failsafe.execute()

            raise

        finally:

            # Stop recorder
            self.recording = False

            if self.recording_task:

                self.recording_task.cancel()

                try:

                    await self.recording_task

                except asyncio.CancelledError:

                    pass

            self.recorder.close()

    async def health_report(self):

        await self.health.print_health()

    async def battery_report(self):

        await self.battery.print_status()

    def current_state(self):

        return self.state_machine.get_state()

    def log(self, message):

        self.logger.log(message)

import asyncio
from MissionComputer.state_machine import MissionState


class MissionExecutor:

    def __init__(self, flight_manager, mission_manager):

        self.fm = flight_manager
        self.mm = mission_manager

    async def execute(self):

        print("\n==============================")
        print("MISSION EXECUTOR")
        print("==============================")

        try:

            await self.mm.run()

        except asyncio.CancelledError:

            print("[EXECUTOR] Mission Cancelled")
            raise

        except Exception as e:

            print(f"[EXECUTOR] ERROR : {e}")

            if self.mm.state_machine:
                self.mm.state_machine.set_state(MissionState.FAILSAFE)

            raise

        finally:

            print("\n==============================")
            print("EXECUTOR FINISHED")
            print("==============================")

from enum import Enum, auto


class MissionState(Enum):
    INITIALIZE = auto()
    CONNECT = auto()
    WAIT_FOR_HEALTH = auto()
    ARM = auto()
    TAKEOFF = auto()
    START_OFFBOARD = auto()
    MISSION = auto()
    WAYPOINT = auto()
    RETURN_HOME = auto()
    LAND = auto()
    DISARM = auto()
    COMPLETE = auto()
    FAILSAFE = auto()
    ABORT = auto()


class StateMachine:

    def __init__(self):
        self.state = MissionState.INITIALIZE

    def set_state(self, new_state: MissionState):

        old = self.state
        self.state = new_state

        print(
            f"[STATE] {old.name}  --->  {new_state.name}"
        )

    def get_state(self):

        return self.state

    def is_complete(self):

        return self.state == MissionState.COMPLETE

    def is_failed(self):

        return self.state in (
            MissionState.FAILSAFE,
            MissionState.ABORT,
        )

    def reset(self):

        self.state = MissionState.INITIALIZE
