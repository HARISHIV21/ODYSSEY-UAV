# Embedded Autonomous UAV Mission Computer

## Overview

A modular autonomous UAV software framework developed using Python and designed for PX4 SITL integration.

## Features

- Mission Computer
- Navigation
- Flight Controller
- Flight Modes
- Mission Planner
- Telemetry
- IMU Sensor
- Battery Monitoring
- State Machine
- Failsafe Manager

## Future Work

- MAVSDK Integration
- PX4 Offboard Control
- Obstacle Avoidance
- AI Vision
- Precision Landing
- Multi-UAV Support
